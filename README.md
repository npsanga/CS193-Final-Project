# Screen-time Session Recorder

Allows a user to create screen time sessions and compare how long they spent vs how long they wanted to spend

## The Problem

A problem I have is that sometimes I tell myself I can have a little break from what I'm doing to scroll. However, when I do this, I often end up scrolling much longer than I intend to.
